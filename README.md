## 📌 Executive Overview

JobAI is an autonomous, end-to-end career intelligence and SaaS copilot engineered by **CodeByTushu**. Built to eliminate recruitment friction, it combines deep ATS resume scoring, real-time job role matching algorithms, and automated cover letter generation with high accuracy.

---

## ✨ Key Features & Capabilities

- **Intelligent ATS Resume Scoring:** In-depth keyword extraction and semantic alignment against job descriptions.
- **Smart Role Matching:** Multi-parameter ranking matching developer experience with hiring requisitions.
- **Application Tracking Pipeline:** Kanban-style board tracking Applied, Interviewing, and Offered stages.
- **Autonomous Cover Letters:** AI-driven context generation personalizing applications for engineering roles.

## 🚀 How to Run & Explore

### 1. Clone this repository
```bash
git clone https://github.com/Tushpendra-Kumar/JobAi-CodeByTushu.git
cd JobAi-CodeByTushu
```

### 2. Launch
- **Web Application / HTML:** Open `index.html` (or main HTML entrypoint) directly in any modern browser (Chrome, Edge, Firefox, Safari) or run via VS Code Live Server.
- **Node / Python Projects:** Follow the respective package installation commands (`npm install` or `pip install -r requirements.txt`).
